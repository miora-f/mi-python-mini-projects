##01 - Calculators

### Rechnung and Trinkgeld Rechner

A simple Python Calculator that allows user to :
- Enter a bill amount
- Choose a tip percentage
- Enter the number of people
- Calculate the tip
- Calculate the total amount
- Split the bill between people

## Technologies
- Python 3
- unittest

how to run : python 01_calculators/rechnung_trinkgeld.py
run test : python -m unittest discover -s tests -v
